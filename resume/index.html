SQL Slammer: Static Shellcode Analysis →

376-byte UDP/1434 worm (CVE-2002-0649). Returns into a sqlsort.dll trampoline at 0x42B0C9DC, walks that DLL's IAT for LoadLibraryA / GetProcAddress, builds API names on the stack, then infinite-loops sendto() against a GetTickCount-seeded LCG. Memory-only, no persistence.

Michelangelo: Full Walkthrough →

1991 MBR/floppy boot virus, Stoned-family. Hooks INT 13h, steals 2 KB of conventional memory by decrementing the BIOS memory-size word at 0x413, and hides the original boot sector on an unused track. On March 6 (Michelangelo's birthday) overwrites successive sectors across every head.

DOS7: Reverse Engineering Notes →

419-byte DOS .COM infector by Lucifer Messiah / Anarkick Systems (1993). On entry, swaps the INT 3 and INT 21h IVT entries — every 1-byte 0xCC opcode now invokes a DOS service, saving bytes and tripping debuggers that breakpoint via INT 3. FindFirst/Next over *.C?M targets, taunt strings on completion.

mystery64: Decompiled Malware Analysis →

Linux x86_64 ELF beacon (course sample, co-analyzed). HTTP-POSTs hostname, username, and a byte-XOR rolling-hash bot ID to an XOR-decoded C2; clock() timing check for debuggers; falls back to a glibc-LCG DGA — three date-keyed .com candidates per day. Most of the binary is dead-stub obfuscation around a small real code surface.
